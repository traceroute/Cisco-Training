OSPF Routing (Open Shortest Path first)
Multi-Vendor Dynamic Routing Protocol
Link State Advertisment
Implements Dijkstra Algorithm
Administrative Distance of 110
Advertised by AREA (Area 0 is the Backbone)

OSPF States:
Down
Init (Initialize)
Two-Way
Ex Start
Exchange
Loading
Full

recipe:
router ospf # <Process ID>
 router-id <ip>
 network <DCN> <wildcard DCN> area <#>

@r4
conf t
router ospf 1
    router-id 4.4.4.4   
    network 10.1.1.8 0.0.0.3 area 34 
    network  4.4.4.4 0.0.0.0  area 34
end

@r3
conf t
router ospf 1
    router-id 3.3.3.3
    network 10.1.1.4 0.0.0.3 area 0
    network 10.1.1.8 0.0.0.3 area 34
    network  3.3.3.3 0.0.0.0  area 0
end


@r2
conf t
router ospf 1
    router-id 2.2.2.2
    network 10.1.1.4 0.0.0.3 area 0
    network 10.1.1.0 0.0.0.3 area 12
    network 2.2.2.2 0.0.0.0  area 0
end

BGP Routing (Border Gateway Protocol)
-Mostly used for WAN
-Administrative Distance of 20
-Also used by ISP and Large Corporations

BGP States:
Notification, Update, Keep-Alive, Open.

recipe for BGP

router bgp # <AS no.>
 bgp log-neighbor-changes
 neighbor <direct IP of next hop> remote-as # <AS. no of neighbor>
 network <network IP between this host and neighbor> mask <SM to neighbor>
